One-click import does not publish directly. After upload, a security preflight and manual confirmation by an authorized user are required.New and updated articles are always returned to draft, The process does not review automatically, create placements or run static publishing.

1. Upload and run preflight

  • Supported formats XLSX, CSV, ZIP, DOCX, MD and Markdown, Maximum upload size 50 MB.
  • DOCX/MD A direct upload imports one article only; Multiple documents require a ZIP, with each file referenced by articles.xlsx or articles.csv manifest rows.
  • DOCX Complex formatting in, unsupported elements, revisions or comments may be downgraded and generate warnings; Macros, ActiveX, OLE, external resources are rejected.
  • Markdown Local images must be packaged with the document in ZIP; For direct uploads Markdown cannot carry local images.
  • The preview stage does not write articles, images, categories, placements or static publishing business data.
