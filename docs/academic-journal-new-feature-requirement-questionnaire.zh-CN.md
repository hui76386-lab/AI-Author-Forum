# 学术期刊新增功能需求确认提问清单

> 用途：供甲方需求访谈、书面确认、范围划分和版本排期使用。  
> 范围：本清单只讨论现有系统之外的新增能力，不包含已有功能缺陷、性能优化和界面修复。  
> 建议填写方式：每项选择“本期需要 / 后期需要 / 不需要 / 待讨论”，并在备注中写明业务规则。

## 17. 建议甲方优先确认的关键问题

以下问题会直接影响数据模型、权限和整体开发范围，应在详细设计前优先确认：

1. 本期是否建设外部同行评审，采用哪种匿名模式；
2. 编辑决定和作者修回需要支持多少种状态和多少轮；
3. 是否建设结构化作者、机构、基金、伦理和许可元数据；
4. 是否需要正式 PDF、补充材料、校样和出版制作流程；
5. 是否注册 DOI，以及需要对接哪些索引和数据报送平台；
6. 是否建设真正的全文检索和引用导出；
7. 是否开放作者及审稿人自主注册；
8. 是否建设更正、撤稿和发布后版本管理；
9. 是否收取 APC 或建设支付、发票和费用减免；
10. 本期明确不做的功能及后续版本边界。

甲方对本清单的回答应在开发前转化为正式需求规格、状态机、角色权限矩阵、页面清单和验收用例。未确认的高风险事项默认不自动发布、不自动覆盖正式数据，也不扩大现有账号权限。
