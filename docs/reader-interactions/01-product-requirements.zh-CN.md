# 01 产品需求与验收边界

## 1. 产品目标

让公开文章保持零门槛阅读，同时让提供并验证邮箱的读者获得三项能力：评论、分享入口和 PDF 下载。系统要在未知流量下可逐级扩展，并让期刊编辑能够按文章治理下载与评论。

## 2. 角色

| 角色 | 定义 |
| --- | --- |
| 匿名访客 | 未验证邮箱，可阅读静态文章和浏览已公开评论 |
| 已验证读者 | 邮箱验证成功且会话有效，可在政策允许时评论、分享、下载 PDF |
| 评论作者 | 创建某条评论的已验证读者，可撤回本人评论和举报其他评论 |
| 期刊编辑 | 对目标期刊有有效主编辑、常务副编辑或副编辑任命的后台账号 |
| 超级管理员 | 平台应急治理和系统运维角色；不能借互动功能绕过文章终审 |

读者身份和后台 `User` 是不同安全域。同一自然人即使邮箱相同，也不能自动获得后台权限。

## 3. 功能规则

### 3.1 邮箱资格

任何受控动作都先检查有效 reader session。未验证读者点击评论提交、分享或下载时，打开同一邮箱验证流程。验证成功后回到原文章和原动作上下文，不要求设置密码。

### 3.2 评论

- 评论区固定在文章正文、作者声明和引用信息之后的文章底部；
- 匿名访客可读公开评论，只有已验证读者可写；
- 普通评论提交成功后立即公开；高风险、疑似垃圾或限流边界评论进入 `pending`；
- 支持对评论回复，首期最大层级为 2：根评论和一层回复；
- 正文长度默认 2 至 2000 个 Unicode 字符，具体阈值配置化；
- 只接受纯文本和换行；HTML 转义，不解析 Markdown、URL、图片、表情包或附件；
- 作者撤回后内容不可恢复公开；存在回复时保留“该评论已由作者撤回”的占位节点；
- 举报原因采用固定枚举加可选说明，举报者身份不公开；
- 编辑隐藏只影响公开展示，不物理删除评论和审核记录；
- 单篇评论区关闭后，历史公开评论默认仍可读，禁止新评论和新回复；管理员可另行设置为整体不可见；
- 关闭、隐藏、恢复、拒绝和撤回都要记录原因、版本和时间。

### 3.3 PDF 下载

- 只提供 PDF，不提供 DOCX、Markdown、EPUB 或资源包；
- 只有当前活动 manifest 中的正式文章版本可以下载；
- 期刊可以有默认下载政策，单篇文章可选择 `inherit`、`enabled` 或 `disabled`；
- 主编辑、常务副编辑、副编辑均可管理其任命期刊内文章的下载政策；
- 启用必须等对应 PDF 产物完成并随新 protected manifest 激活后生效；
- 禁用运行时授权应立即拒绝新申请，已签发链接的最长残余窗口由链接 TTL 限制；默认 5 分钟；
- 下载按钮只有在当前版本存在有效 PDF 且政策允许时才显示为可用。

### 3.4 分享

- 分享前要求有效 reader session；
- 支持 `navigator.share()` 的环境调用系统分享面板；
- 不支持时提供复制 canonical URL；
- 系统不读取通讯录、不收集接收者、不代发邮件、短信、WhatsApp、微信或社交平台消息；
- 文章是公开 URL，系统不能阻止读者手工复制地址；“要求邮箱”只约束站内分享按钮和事件，不是 DRM。

## 4. 非功能需求

- 静态文章阅读不依赖互动 API、Redis、邮件或评论数据库；
- 动态服务支持横向扩容，不使用本机内存保存会话或限流真值；
- 所有写接口可幂等重试；关键审核和政策变更有不可变审计；
- 海外用户优先，邮件与 CDN 的生产供应商必须有目标地区覆盖；国内团队的本地开发不依赖生产邮件；
- 隐私默认最小化，不做营销画像；原始邮箱不得进入普通日志、埋点或 trace；
- 移动端和桌面端均满足键盘、屏幕阅读器、焦点和错误提示要求；
- 未知流量通过上线前基准压测和容量分级确定，不以主观 QPS 替代验证。

## 5. 首期非目标

- 读者密码登录、社交登录、关注、订阅、点赞和私信；
- 管理员主动向第三方平台推送分享消息；
- 评论 Markdown、富文本、图片、附件、可点击链接和多层无限嵌套；
- PDF 个性化水印、按读者生成不同文件或离线 DRM；
- 把读者邮箱同步到营销系统；
- 对历史未发布 revision 提供 PDF；
- 用互动系统改变文章审核、投放或静态发布状态。

## 6. 关键验收场景

1. 匿名访客能在互动服务完全不可用时阅读静态文章。
2. 匿名访客点击下载后完成邮箱验证，返回原文章并获得短时 PDF 下载。
3. 普通评论立即展示；命中高风险规则的评论只对本人显示“等待审核”。
4. 评论作者可撤回本人评论，不能撤回他人评论；有回复时保留占位。
5. 举报不会自动公开举报人；重复举报被幂等合并或限流。
6. 三种有效期刊编辑角色都能修改本刊文章下载政策，不能操作其他期刊。
7. 关闭评论区后写接口拒绝新评论和回复，已公开评论按配置保持可读。
8. PDF 禁用后不再签发链接；旧短链到期后无法访问。
9. 文章 slug 变更后，历史评论仍通过 `article_public_id` 关联到同一文章。
10. 回滚静态 release 时，页面、能力投影和 PDF protected manifest 回到同一已验证版本。

## 7. 待上线前配置项

以下不是需求缺口，不阻塞开发，但必须在生产上线评审时填入：邮件供应商和发件域、数据驻留区域、隐私主体名称、客服/滥用邮箱、数据保留周期、CDN/WAF 供应商、目标 SLO、压测流量模型和预算告警阈值。
